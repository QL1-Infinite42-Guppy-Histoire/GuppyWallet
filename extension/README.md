# GuppyWallet ブラウザ拡張機能版

42 Chain（Infinite）と QL1 のためのウォレット拡張機能（Chrome / Edge など Chromium 系）。
スマホアプリ版と同じ復旧フレーズで、**同じウォレット**が開けます。

## 機能（v0.1.0）
- ウォレット作成／復旧フレーズでの取り込み（導出はアプリと同一: m/44'/60'/0'/0/0）
- パスワードで暗号化した金庫（PBKDF2 60万回 + AES-256-GCM）をブラウザ内ストレージに保存。
  秘密鍵はポップアップを開いている間だけメモリに置き、閉じると消えます
- 残高表示（42 Chain / QL1、円換算つき・DEX価格ベース）
- 送る（確認画面、25/50/75/MAX チップつき）／受け取る（QR表示）
- Fluke: 参加 → めくる → 確定（= 新しい Guide の発行）まで完結。
  確定の署名は公開の乱数ネットワーク drand から取得（アプリ版と同じ仕組み）
- 確定成功時のオリパ風開封演出（実物の Guide カード・実データのティア連動グロー）

## 入れ方（開発者モード）
1. Release から `guppy-wallet-extension.zip` をダウンロードして解凍
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で、解凍したフォルダを選ぶ
4. ツールバーの拡張機能アイコンから GuppyWallet を開く

## 開発
```sh
npm install
npm run build      # dist/ にビルド（manifest.json がルートに入ります）
npm run typecheck
```
アプリ側の純粋な TS ライブラリ（チェーン設定・残高・価格・Fluke/drand）を
`../../src` から直接 import して再利用しています（二重管理なし）。

## v1 に入っていないもの
- サイト側からのウォレット接続（window.ethereum / EIP-1193）→ v2 予定
- Swap・LP・ステーキング・ブリッジ・入金（アプリ版にはあります）
